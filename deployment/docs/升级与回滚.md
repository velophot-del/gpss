# 升级与回滚

## 升级前

```bash
./deploy.sh doctor
./deploy.sh backup
```

保留旧部署目录和刚生成的备份。不要复用旧压缩包内的 `.env.deploy` 示例覆盖真实配置。

## Docker升级

1. 解压新版本到新目录。
2. 将旧目录的 `.env.deploy` 复制到新目录并保持权限600。
3. 先运行 `docker compose ... config`，再执行 `./deploy.sh install`。
4. 执行 `./deploy.sh doctor`。

Compose项目名固定为 `gpss`，数据库卷和上传卷会继续使用。初始化脚本幂等，不会重复创建管理员或演示数据。

## 回滚

切回旧部署目录并执行 `./deploy.sh up`。如果升级修改了业务数据，再按《备份恢复》恢复升级前备份。不要删除Docker卷。

原生部署升级前应复制 `/opt/gpss` 并备份数据库和 `/var/lib/gpss/uploads`；回滚时恢复三者并重启 `gpss` 与Nginx。
