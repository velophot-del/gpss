# 备份与恢复

## Docker备份

```bash
./deploy.sh backup
```

备份保存在 `backups/时间戳/`，包含：

- `database.sql.gz`
- `uploads.tar.gz`
- `MANIFEST.sha256`

建议将备份复制到另一台设备或对象存储，并定期抽查恢复。

## Docker恢复

```bash
./deploy.sh restore /完整路径/backups/时间戳
```

脚本会先校验文件，再要求输入 `RESTORE`。恢复会覆盖当前数据库和上传文件，不能只凭目录名称推断备份内容。

## 原生部署备份

使用MySQL专用账号导出数据库，并单独备份 `/var/lib/gpss/uploads` 和 `/etc/gpss/gpss.env`。环境配置包含密钥，备份文件必须加密并限制权限。
