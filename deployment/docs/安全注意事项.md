# 安全注意事项

- 首次登录后立即修改管理员密码。
- 正式包默认关闭 `/debug` 演示入口和 `/api/auth/demo-login`。
- `.env.deploy`、`/etc/gpss/gpss.env`、数据库备份不得通过聊天、邮件或公开网盘发送。
- 防火墙或阿里云安全组只开放80/443；禁止公开3011和3306。
- 使用公网域名时启用HTTPS，并定期更新证书。
- 系统仍使用存在已知风险的 `xlsx` 依赖；仅允许受信任管理员导入来源可信的Excel文件。
- 定期运行备份与恢复演练，并更新Node、MySQL、Nginx和宿主机安全补丁。
- 不要运行 `docker compose down -v`，不要手工删除MySQL或上传文件卷。
