# 毕业资料模板使用说明

任务书、开题报告书和中期检查表使用管理员在所属周期确认并发布的 DOCX 模板。上传文件保留原样；在线材料第一次保存时绑定模板版本及填写区域配置。新版发布后，已绑定材料继续使用原版本。

## 管理员

1. 在“毕业资料库”上传对应周期的 DOCX，保存为草稿。
2. 点击“核对填写区域”。逐项检查栏目来源：管理员固定、学生填写、系统信息、教师意见。展开行可核对模板原文、调整段落范围；签名和日期区应保留固定。
3. 在固定内容中编辑需要统一调整的阶段名称、工作内容、年份和时间。保留未更改原文时无需输入。
4. 下载生成预览，用 Word 核对固定文字、示例位置、格式、签名区以及长文本分页。检查无误后勾选确认并发布。
5. 修改已确认模板时，上传新版本、重新核对并发布。管理员可下载原件；生效空白模板会应用固定内容并清空填写区。

识别结果是待核对建议，不能代替管理员核验。普通段落和非嵌套表格可配置；嵌套表格、填写区中的文本框及部分复杂对象不支持，需调整模板或填写范围。不同 Word 程序、字体和填写长度可能影响分页。

## 学生和教师

学生打开对应毕业流程，查看管理员固定内容并填写动态栏目，保存草稿后可下载预览，按阶段提交教师审核。教师查看学生填写内容和同一版本的固定内容。

历史材料不会自动改用新版。尚未绑定模板的历史材料由管理员在对应模板配置界面选中并明确关联；其原填写记录保留。旧记录缺少模板必填内容时，系统会阻止关联，管理员须先核对历史内容及模板字段标识，避免把空栏目固定到已确认材料。模板不可用或文件发生变化时，系统阻止导出并提示管理员处理，不自动套用其他模板。

## 数据库升级

新建数据库通过现有 `db:init` 创建所需表。已有数据库需使用其原有数据库连接配置，在 `server` 目录执行 `npm run db:migrate-templates`；该脚本只创建模板配置及材料版本绑定表。正式环境操作应按现有发布流程和备份要求执行。
