# 教师遴选：一次审核与志愿逐轮递补

教师一次审核全部申请，可提前填写低志愿的拟录取、候补或不录取意见，并按课题保存和提交。拟录取及候补都是接收意见，不代表正式录取，不占正式名额，名单可超过课题招生人数。

系统统一结算时先处理所有第一志愿，再处理第二至第六志愿。只有尚未被更高志愿最终录取的学生才参与后续轮次；高志愿因名额不足未录取也可进入低志愿，不要求教师先明确拒绝。同志愿内拟录取优先候补，再按教师设置的顺序择优；排序相同时按申请时间及申请编号稳定排序。

课题有空额时从已认可候选中自动递补，教师无需再次操作。最终录取不得超过课题容量或教师指导上限，每名学生最多录取一个课题。已有正式录取保持不变；未处理与不录取意见不自动转为接收。候选耗尽仍有空额时留待调剂。

多个课题共享教师上限时，较高志愿优先；同轮按接收决定、教师排序、申请时间及申请编号确定顺序。原有课题容量合计配置校验保持不变。

所有课题提交或到达截止时间后统一结算；未提交名单按截止时已保存草稿自动提交。提交后修改仍需管理员退回；本规则适用于尚未结算的名单，不自动重算已完成结算。
