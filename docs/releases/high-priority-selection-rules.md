# 教师遴选：高志愿绝对优先规则

## 教师操作

教师仍可对每名申请学生选择“拟录取、候补、不录取”，并保存草稿后提交本课题名单。提交不会立即改变学生最终录取结果；所有课题提交或到达截止时间后，系统统一结算。

## 志愿处理

1. 第 1 至第 6 志愿按数字从小到大确定优先级。
2. 较高志愿处于“拟录取”或“候补”时，较低志愿已有的拟录取、候补会显示“高志愿暂停”，不占用低志愿名额，也不计入教师拟录取人数。
3. 暂停不是不录取：系统保留低志愿教师的原始决定、候补顺序和操作记录。
4. 高志愿改为“不录取”或清除决定后，低志愿意见自动恢复为有效候选，并在统一结算时重新按名额、候补顺序和教师指导上限计算。
5. 高志愿最终录取后，其他志愿转为“因高志愿录取而退出”。
6. 高志愿未处理或已设为“不录取”时，不暂停低志愿。

## 截止与结算

截止时间到达后，尚未提交的课题草稿自动提交。教师未作出任何决定的学生不会被系统擅自设为录取或候补；其申请在统一结算后按未匹配处理，进入后续调剂安排。
