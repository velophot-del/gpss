# 第一志愿拟录取与候补递补规则

本周期所有课题合计使用教师指导人数上限。页面顶部显示教师指导上限、跨全部课题的拟录取总人数、已正式录取人数及剩余名额。剩余名额按“指导上限减本教师本周期所有课题拟录取人数”计算，包含当前未保存修改；候补不计入，超额时显示负数及提示。拟录取不等于正式录取，最终结算仍按实际录取上限执行。

仅第一志愿允许设置拟录取。第二至第六志愿可设置候补或不录取；第一志愿也可设置候补。系统优先完成第一志愿录取，教师实际录取人数达到上限后停止接收候补；尚有名额时，按第二至第六志愿逐轮递补教师选中的候补。每个课题自身名额限制仍有效，已有正式录取先占名额。

例如上限15人：跨课题第一志愿实际录取15人时，无名额递补；第一志愿实际录取10人且无既有录取时，最多再递补5人。统计依据是实际录取而非第一志愿申报人数。

保存草稿保留未处理状态。手动提交及截止自动提交时，未选择拟录取或候补的可审核申请显式记为本课题不录取，不影响学生的其他志愿。提交前提示本次未处理人数。

旧版尚未结算名单中的低志愿拟录取按候补接收意愿处理；草稿读取及提交时保留原候补顺序，将旧低志愿拟录取接续其后。已正式录取和已完成结算不重算。调剂流程沿用原规则。
