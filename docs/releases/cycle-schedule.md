# 按时间自动切换周期阶段

已启用的周期（active、selection、review、adjustment）由后端启动时检查，此后每分钟检查一次。无时区日期按北京时间解释；带时区的时间保留其原始时区。

阶段按顺序推进：课题发布 → 志愿填报 → 教师遴选 → 结果公示 → 调剂。每一步使用下一阶段的开始时间，不配置开始时间则保持当前阶段。不会回退管理员已提前切换的阶段，不开启草稿，不重开结束周期，也不自动结束调剂或进入任务书阶段。服务停机跨过多个阶段时按顺序补查。

进入教师遴选必须通过原有截止时间及教师课题名额合计校验，且截止时间晚于开始时间。进入结果公示必须已到遴选截止时间并成功完成结算；进入调剂必须有已完成录取结算及有效调剂截止时间。

配置冲突、结算失败会保留当前阶段并在管理员“遴选结算”页面显示定时检查错误。修正配置后下次检查重试。教师页面刷新后读取新阶段。

本功能不会取消指导人数上限，也不会解决被容量配置校验拒绝的409；需先按错误提示修正配置。

## 手动切换与本周期人数冲突例外

管理员在“选题周期管理”的编辑窗口选择“阶段切换方式”：自动按配置时间推进，手动保持管理员选择的阶段。列表的“手动切换状态”菜单会同步将本周期设为手动模式，之后定时任务不会覆盖人工所选阶段。重新编辑选择自动模式后，下次定时检查恢复按时间向前推进。阶段切换模式不取消截止自动提交与结算。

编辑窗口中的“课题名额合计冲突”默认校验，选择“本周期忽略”后，进入教师遴选和普通录取结算都跳过该周期的课题设置名额合计冲突检查。其他周期不受影响。最终实际录取仍遵守教师总指导人数、单课题名额、一人一课题和志愿轮次规则；有效截止时间仍为必填。

当前周期进入遴选操作：编辑当前周期，选择管理员手动切换，开启本周期忽略名额合计冲突，配置尚未到期的有效遴选截止时间，状态选择审核中后保存。也可先保存这些选项，再使用列表“手动切换状态 → 进入审核”。

进行中周期使用列表手动切换时，会同时开启并保存本周期的容量合计例外，无须先编辑保存该选项；草稿等未启用周期不会默认开启例外。编辑页仍可调整该选项。
