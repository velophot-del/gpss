# 结算后重新开放补录

## 使用方式

1. 在周期管理中将当前周期设为调剂阶段，并设置未来的截止时间。
2. 在管理员“调剂结算”页点击“重新开放补录”，核对精确到秒的截止时间并填写原因。
3. 操作成功后，让未录取学生刷新页面，重新选择并保存 1–6 个调剂志愿；旧志愿不会自动参加新一轮。
4. 新截止时间到达后，系统按现有匹配规则结算，仅处理新提交的志愿。

修改周期时间本身不会重新开放已完成结算。创建和编辑的全部阶段时间支持选择时、分、秒，按设备时区显示并携带时区偏移保存；周期列表增加精确到秒的调剂截止时间。00:00:00 表示当天开始。既有截止时间不会自动延长。

## 数据与并发保护

- 新增 adjustment_round_archives 表；按单调递增的归档顺序获取最新轮次标识。
- 单一事务保存旧结算、全部调剂志愿、旧教师批次和草稿的完整 JSON 快照，再清空这些当前轮次记录；正式 applications 录取及课题名额不变。
- 保存操作原因和审计日志，管理员可查看历史结算汇总。
- 重新开放必须取得首轮及调剂结算锁；事务内核对周期、未来截止时间和原结算 ID。重复或过期请求拒绝。
- 学生请求同时携带轮次 ID 和志愿版本；读写在周期行锁内核验，旧轮次的请求无法因版本号重复而写入新轮次。
- 定时结算捕获轮次 ID，取得锁后重读轮次及截止时间；旧请求在任何结算写入之前被拒绝。
- 归档或审计写入失败则整笔回滚。匹配器继续把全部已有正式录取作为锁定分配，计入课题与导师上限。
